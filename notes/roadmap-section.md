## Ścieżka Frontend Developera

Plan rozwoju platformy — kolejne kursy, które pomogą Ci przejść całą drogę frontend developera.

### Kursy

1. Pełny kurs HTML
   Zacznij tworzyć swoje pierwsze strony.

2. Podstawy CSS
   Zacznij stylować swoje strony internetowe.

3. Podstawy JavaScript (js-basics/js-logo.svg)
   Dodaj interaktywność do swoich stron.

4. Zaawansowany JavaScript (advanced-js/advanced-js-logo.svg)
   Wszystko co potrzebujesz wiedzieć przed nauką framework'ów.

5. Pełny kurs React (react/react-logo.svg)
   Twórz nowoczesne, interaktywne aplikacje webowe.

6. Nowoczesny CSS (modern-css/modern-css-logo.svg)
   Naucz się projektować i stylować nowoczesne strony internetowe.
