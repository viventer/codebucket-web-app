# CodeBucket

## Product

Platform for learning programming through:

- short lessons
- quizzes
- coding exercises
- projects (guided and individual)

## Target audience

Beginner web developers.

## Current MVP

Available:

- HTML & CSS Basics course

Pre-sale:

- Advanced CSS course
- JavaScript course

## Technical decisions

- Next.js App Router
- Firebase Auth
- Firestore
- Redis
- Tailwind
- shadcn/ui
- react-monaco

## Coding conventions

- TypeScript only
- Zod validation
- Server Actions when possible
- No any types
- avoid unnecessary client components

## Business model

Courses are promoted through YouTube.

Most YouTube videos are educational previews that introduce concepts without covering the entire learning path.

Exception:
Beginner courses, such as HTML & CSS Basics, are available on YouTube for free.

Premium courses on CodeBucket include:

- Interactive exercises
- Quizzes
- Individual projects
- Final projects
- Progress tracking
- Structured learning path

Users pay for guided practice and a complete learning experience, not just access to videos.
